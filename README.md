An Android-based digital governance and record management application designed to streamline village administration processes through a simple and accessible 
mobile interface.

Overview
GRAMAKHATA is developed to digitize and simplify administrative workflows such as record management, citizen data handling, and local governance operations.
The application focuses on improving accessibility, reducing manual work, and enhancing efficiency through a mobile-first approach.

Features

* User-friendly Android interface
* Digital record management
* Secure data handling
* Organized administrative workflows
* Real-time data access and updates
* Scalable architecture for future enhancements

Tech Stack

* Kotlin
* Android Studio
* Gradle
* XML Layouts
* Android SDK
